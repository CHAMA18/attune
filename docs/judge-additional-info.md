## If this was an existing project, in what ways did you significantly upgrade and improve it to work with Qloo?

Attune’s initial app shell was created during the hackathon period. We integrated Qloo place search and Insights to resolve venue context and explore affinities between places and artists. We then built a shift-planning experience around those signals, including venue-specific inputs, daypart suggestions, evidence panels, and a comparison of related artists for two places. A server-side proxy keeps the Qloo API key out of the browser, while the interface distinguishes Qloo signals from operator inputs and locally calculated summaries.
